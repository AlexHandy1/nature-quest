## Decisions and trade-offs

- **Decision:** Rename Nature Walker → Nature Quest everywhere except historical `WORK_SUMMARY_*.md`/`PLANNING_*.md` files (left untouched, treated as historical record). **Why:** explicit user call, resolving a "still open" item flagged across many prior sessions. **Trade-off:** none.
- **Decision:** `planning_and_status_docs/` → `docs/`, with `status_docs/`/`prds/`/`specs/`/`decisions/` subfolders, as the standing convention across both this project and the `ai-agent-knowledge-bank` skill templates. **Why:** documentation tidy-up requested by the user; `docs/` is a more conventional, reusable name for future projects built from the same skill templates. **Trade-off:** none; `git mv` preserved history.
- **Decision (ADR-001–ADR-004):** GCP Cloud Run monolith, monorepo, Vite+React+TS (full scaffold now), FastAPI. **Why/Trade-off:** see each ADR — all trace back either to matching current scale (solo maintainer, low traffic) or to concrete evidence already in this project's own history (the duplicated-JS bug for React; the flagged "background-job/polling" prototype gap for FastAPI's native SSE support).
- **Decision (ADR-005):** Terraform + remote GCS state backend; GitHub Actions + Workload Identity Federation; CI gate = lint/typecheck → unit tests → build/deploy → post-deploy smoke test; CI designed from the start for safe fork-PR handling. **Explicitly not fully settled** — flagged to revisit once real implementation experience with Terraform vs. imperative `gcloud` scripts exists, per user direction, without leaning on stated personal experience as the deciding factor in the document itself. **Why:** Terraform's plan/diff review benefits a project open to external infra-change proposals; remote state removes the specific security exposure a scripted approach would also have avoided, at low cost. **Trade-off:** real config/learning-curve cost vs. a simpler imperative alternative — open question, not closed.
- **Decision (ADR-006):** Secret Manager; single prod environment (env name as a Terraform variable); new dedicated GCP project, `europe-west1`; interest-capture data is query text + timestamp only (no email/PII), structured logs only, also forwarded to PostHog; default Cloud Run URL. **Why:** proportionate to current "coming soon" scale; EU-leaning region/PostHog hosting keeps infra consistent with the consent story. **Trade-off:** revisit storage if richer querying/export is needed later; region migration isn't free if the real user base skews elsewhere.
- **Decision (ADR-007):** PostHog EU Cloud, consent-gated (`opt_out_capturing_by_default` + a custom, not third-party, consent banner), client + server-side capture of the same event (server-side only fires when the client-reported consent flag is true — designed this session, not pre-existing in any ADR before the spec was written); Cloud Armor rate limiting as the primary, fully-disclosed anti-abuse control. **Why:** PostHog's SDK owns actual consent enforcement; a third-party CMP is disproportionate for a two-button banner; a control that only works while its mechanism is secret isn't a real control once the code is public. **Trade-off:** consent banner wording is self-drafted, not formally legally reviewed — an explicit, deliberate user call given project scale, not an oversight.
- **Decision (ADR-008):** Nature Quest is open source from its first commit, code and docs both — not made public later. **Why:** explicit user goal, to let other developers contribute or fork/rebuild from day one. **Trade-off:** no security control may rely on obscurity; CI/CD must be fork-PR-safe from the start; a LICENSE decision is now a blocking open item; every future ADR/spec must assume a public, potentially adversarial reader.
- **Decision:** No PII (no email or other identifying field) collected anywhere in the interest-capture flow; consent-banner copy is a short, self-drafted, plain-language disclosure rather than formally reviewed legal text. **Why:** explicit user privacy stance, and a pragmatic call that formal legal review isn't proportionate to this project's current scale. **Trade-off:** some legal risk knowingly accepted rather than resolved.
