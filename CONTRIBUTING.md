# Contributing

Nature Quest is public from its first commit (see `docs/decisions/ADR-008-open-source-from-day-one.md`), but it's an early-stage solo project — not yet actively seeking external contributions or shares. This file is a placeholder; a full contribution guide will follow once the project is ready to onboard outside contributors.

`main` is branch-protected: no one can push to it directly, and merging a PR requires the maintainer's approval. Only the maintainer has credentials able to deploy.

A LICENSE has not been chosen yet, so the terms under which this code may be used, forked, or contributed to are undefined for now.
